O que acontece

  1. A API (sales.joshuel.com.br, região que o Cloudflare escolher) grava a venda como PENDING na tabela global e publica o evento.
  2. O evento chega à fila das duas regiões. Só o worker da região ACTIVE consome; a PASSIVE guarda a cópia para um failover.
  3. O worker gera o recibo no S3 (replicado para a outra região) e marca a venda como PROCESSED.
